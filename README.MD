# 🏗️ Architecture Patterns in TypeScript

> Образовательный проект, демонстрирующий реализацию ключевых архитектурных паттернов и принципов проектирования на чистом **TypeScript** без использования тяжелых фреймворков.

---

## 🚀 Что внутри (Реализованные паттерны)

Проект решает одну и ту же задачу (управление списком пользователей: валидация, добавление, удаление), но каждый раз реализован через **принципиально разную организацию слоев и потоков данных**:

1. **MVC (Model-View-Controller)** — Модель напрямую уведомляет Представление через механизм подписки (`subscribe/notify`), Контроллер управляет состоянием.
2. **MVP (Model-View-Presenter)** — Представление полностью пассивно. Презентер выступает единственным посредником между Моделью и Представлением (`view.render()`).
3. **MVVM (Model-View-ViewModel)** — Реализация реактивного связывания данных (`Data Binding`) и команд.
4. **Clean Architecture** — Строгое разделение ответственности по слоям через интерфейсы-порты, интеракторы (`Use Cases`) и шлюзы.
5. **Onion Architecture** — Концентрическая архитектура, где бизнес-логика и доменное ядро изолированы от внешнего мира и инфраструктуры.
6. **SOLID** — Примеры принципов объектно-ориентированного программирования (`src/solid.ts`).
